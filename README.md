# BeRo

BeRo is a mobile-first prototype combining global eSIM connectivity and travel safety services.

## Current prototype

- Japan travel connectivity dashboard
- Remaining data gauge (7.4 GB)
- Japan 10GB plan and recharge action
- Local call shortcut
- BeRo Safety / 24H customer support shortcut
- Japanese local number card
- Bottom navigation: Home, eSIM, Travel, Settings
- PWA manifest and offline service worker

## Run

Open `index.html` in a browser or deploy the repository as a static site.

## Install on iPhone

Once deployed over HTTPS, open the site in Safari and choose **Share → Add to Home Screen**.
